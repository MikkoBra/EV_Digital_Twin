# Electric Vehicle Digital Twin

This repository contains code for a digital twin of an electric vehicle. It was created for the
Digital Twin Engineering course of 2025.  
Team: O  
Authors: Jasper Abbes, Mikko Brandon, Yonatan Getachew, Koen Verlaan

---

## Project Structure

```text
.
├── Publish_Data.py              # Publishes EV data to HiveMQ Cloud at a specified rate
├── Receive_Data.py              # Receives and processes data from HiveMQ Cloud
├── System_State.py              # Implements the Digital Twin and ML prediction functions
│
├── models/                      # Error code prediction models and outputs
├── dtc_prediction/              # LSTM time-series model and preprocessing for DTC prediction
├── anomaly_detection/           # ML model and preprocessing for anomaly detection
├── data/                        # Contains CSV datasets for 4 EV usage types
└── dashboard/                   # GUI implementation of the digital twin
    ├── assets/
    ├── components/
    ├── pages/
    └── services/
```

## Getting Started

### Requirements

- Python 3.8+
- pip installed

### Installation

In the root directory, run the following command to install dependencies:

    pip install -r requirements.txt

---

## Running the Application

The dashboard interface can be launched using:

    python dashboard/gui.py

This starts the EV Digital Twin Dashboard, providing a visual representation of the vehicle’s system state, model predictions, and anomalies.  

### Running Data Replay

Clicking the green play button opens a settings window. Once the desired settings are input, the data replay can be started. Note that although
replay speed can be set, the replay may slow down significantly once the ML models have enough historical data to start making predictions.

### Pausing Data Replay

Clicking the yellow pause button pauses the data replay. The replay continues when this button is pressed again. The green play
button can also be used to resume the simulation.

### Stopping Data Replay

To fully end the simulation and disconnect from the messaging service, press the red stop button. To start a new simulation, the green play
button must be pressed.

### Data Overviews

The most important state parameters are always visible on the right side of the GUI. To see all current parameter values, hover over a wheel,
the battery or a motor to see their respective parameters' states. If one of these elements is clicked, the historical overview of said parameters
is opened.

## Core Modules

### 1. Publish_Data.py
- Contains class EVDataPublisher
- Publishes simulated EV telemetry data to HiveMQ Cloud
- Sends data at a specified rate to be received as events by the subscriber

### 2. Receive_Data.py
- Contains class EVDataReceiver
- Subscribes to the HiveMQ Cloud topic and receives published data
- Processes incoming data into a readable and structured format

### 3. System_State.py
- Contains class DigitalTwin
- Maintains the internal state representation of the EV
- Calls implemented ML models to make predictions and update the system state dynamically

---

## Machine Learning Components

### /models
- Includes trained models for predicting diagnostic error codes and their output logs.

### /dtc_prediction
- Contains Python scripts for:
  - Implementing an LSTM time-series model
  - Predicting error code occurrences for the next 24 timesteps
  - Data preprocessing and feature engineering for time-series inputs

### /anomaly detection
- Includes ML models and preprocessing functions for detecting anomalies in system state parameters in real time.

## Data Description

### /data Directory
Contains CSV datasets of four electric vehicles with varying driving profiles:

| File Name | Description |
|------------|-------------|
| rare_user.csv | Very light usage — occasional city trips, minimal stress on components. |
| moderate_user.csv | Balanced daily commuting and occasional long drives. |
| heavy_user.csv | High-intensity usage including commercial or inter-city driving. |
| daily_user.csv | Average usage pattern across urban and semi-urban environments. |

## State Parameters

| Parameter | Description |
|------------|-------------|
| timestamp | Date and Time of reading (format: DD-MM-YYYY HH:MM:SS) |
| soc | State of Charge (%) |
| soh | State of Health (%) |
| charging_cycles | Total number of full charging cycles completed |
| battery_temp | Battery temperature (°C) |
| motor_rpm | Motor speed in revolutions per minute |
| motor_torque | Torque generated by motor (Nm) |
| motor_temp | Motor temperature (°C) |
| brake_pad_wear | Brake pad wear percentage |
| charging_voltage | Charging voltage (constant at 400V) |
| tire_pressure | Tire pressure (PSI) |
| dtc | Diagnostic Trouble Code recorded at timestamp (if any) |
